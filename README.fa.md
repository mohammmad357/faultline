# Faultline — خط گسل

**یک شبکه، دو موتور، یک تاریخچهٔ تصادفی.**

![نتایج آزمایش](assets/experiment.svg)

این پروژه انتشار SIR روی شبکهٔ مصنوعی را با روش رویدادمحور Gillespie در Python و C شبیه‌سازی می‌کند. جذابیت اصلی، بازتولیدپذیری بین دو زبان است: با ورودی یکسان، شبکه و تمام رخدادهای گسسته یکسان می‌شوند. زمان‌ها با تلورانس مشخص مقایسه می‌شوند.

موتورها وابستگی خارجی ندارند. نمودارها با matplotlib تولید می‌شوند. مدل برای آزمایش ریاضی است؛ نرخ‌ها و شبکه‌ها مصنوعی‌اند و ابزار پیش‌بینی بیماری واقعی نیست.

```sh
mkdir -p build
gcc -std=c11 -O2 -Wall -Wextra -Wpedantic -Werror c/faultline.c -lm -o build/faultline
python python/faultline.py 200 2 3 1 314159
./build/faultline 200 2 3 1 314159
python -m unittest discover -s tests -v
```

ورودی‌ها به ترتیب: تعداد گره، تلاش اتصال تصادفی به‌ازای هر گره، نرخ انتقال به‌ازای هر یال، نرخ بهبود به‌ازای هر فرد، بذر. شبکه ابتدا یک حلقه است؛ اتصال‌های تصادفی تکراری و خودحلقه حذف می‌شوند. گره صفر ابتدا آلوده است و بازیابی برگشت‌ناپذیر است.

- ۳۰۰ مسیر کامل Python/C با هم مقایسه و به‌صورت مستقل بازپخش می‌شوند.
- آزمون تحلیلی بدون انتقال و آزمون آماری دو گره وجود دارد.
- ۱۸۰ اجرا در سه سناریو، دادهٔ خام و نمودار توزیع منتشر شده است.
- CI دو نسخهٔ Python و sanitizerهای C را اجرا می‌کند.
- گزارش سرعت شامل راه‌اندازی پردازش، ساخت شبکه، شبیه‌سازی و خروجی CSV است.

برای بررسی مهندسی، [قرارداد بازتولیدپذیری](MODEL.md)، [نتایج واقعی](results/RESULTS.md) و [یادداشت رزومه و مصاحبه](RESUME.md) را بخوانید. اتصال بیشتر هم‌زمان تراکم شبکه را تغییر می‌دهد؛ این آزمایش اثر خالص اتصال میانبر را جدا نمی‌کند. همهٔ مسیرهای خاموش‌شدهٔ زودهنگام نیز در نتایج لحاظ شده‌اند.

پیاده‌سازی مرجع در هر رخداد یال‌ها را مرور می‌کند؛ برای میلیون‌ها گره طراحی نشده است. RNG کوچک xorshift32 محدودیت آماری دارد و برای مطالعات علمی بزرگ باید ارزیابی و جایگزین شود. پروژه با کمک هوش مصنوعی آماده شده؛ ادعاهای فنی به کد و آزمون قابل اجرا متصل‌اند.

راهنمای کامل و فرمان‌های PowerShell در [README انگلیسی](README.md) است. مجوز MIT.
